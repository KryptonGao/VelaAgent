# Vela 0.0.2

Vela 0.0.2 adds an English interface alongside Simplified Chinese, making the app usable in either language.

## What's new

- **English interface:** Switch between English and Simplified Chinese in Appearance settings. The selected language applies across the app, including menus, file dialogs, workspace changes, model settings, and error messages.

## Download

| File | Platform |
| --- | --- |
| `Vela-0.0.2-arm64.dmg` | macOS (Apple Silicon) |
