三大招牌體驗

先看結果，想看過程時再展開

01

緊湊模式

把工具呼叫收成過程行，讓任務內容佔據主要視野。

  • 讀檔案、改程式碼、執行命令以單行呈現，連續呼叫自動合併為可展開的摘要。
  • 點檔名開右側預覽，展開改動看 diff，展開命令看輸出。
  • 完成後可收起整輪過程，只保留結論。
  • 偏好卡片？可在「設定 → 外觀」切換工具顯示。
02

Codex 同款 SubAgents

主代理統籌，子代理並行查閱、實作與審閱。

  • 用 spawn_agent 拆分任務、send_message 交換發現、followup_task 繼續派工。
  • 子代理還能建立自己的子任務，形成 /root/auth 這樣按路徑組織的代理樹。
  • 點代理路徑，在右側獨立面板檢視其訊息、思考、工具呼叫與結果，並以分頁切換。
  • explore 唯讀查閱；general 沿用目前會話權限。子代理會話會持久化，重開聊天可恢復。
03

DeepSeek Harness 同款軌跡介面

從對話切到軌跡，逐節點檢查 Agent 如何得出結果。

  • 時間軸與事件列表聯動，展示思考、工具呼叫、回傳與助手輸出。
  • 可按時長、輪次或模型呼叫檢視；選中節點即看參數、結果、Schema 與計時。
  • 請求指標涵蓋首 Token 延遲、生成耗時、Token 用量與快取命中率。
  • 初始系統提示詞與工具定義同樣可查看。

截圖由 VelaHarness 的真實介面元件搭配示例資料渲染。atlas-web 專案、對話、測試結果、耗時與 Token 指標僅作展示，不代表真實任務紀錄或效能基準；「同款」描述的是互動體驗與介面組織方式。

更多工作能力

🧠

專案記憶與全域記憶

兩份純 Markdown 檔：跨專案的個人偏好，與目前專案的慣例和決策。每次執行前自動載入，可在「設定 → 記憶」檢視、編輯、清空或刪除。

- 文件正文使用簡體中文
- 決策：redirect 僅允許站內路徑
🌿

本機工作區與 worktree

在原工作區，或在獨立的 vela/wt-* 分支 worktree 中處理任務。

🔍

審閱與工作面板

檢視 Git 差異與暫存狀態；右側分頁承載檔案預覽、變更與整合終端機，⌘T 新增分頁。

🔌

MCP 伺服器

連接本機或遠端 MCP 工具；支援全域與專案設定、按需探索、專案信任與唯讀授權。

⏰

定時任務

一次、每日、每週或 Cron 排程；每次執行都在綁定工作區的新對話中進行。

📋

任務配方

儲存參數化任務模板，填入參數、預覽後在新對話中啟動。支援 Agent / Plan、版本快照、專案庫與匯入匯出、Skill 依賴、定時綁定與獨立 worktree，以及結構化階段、條件分支、審批與團隊共享。

/fix-bug/review-changes/prepare-release
🌐

瀏覽器面板

連結可在面板分頁中開啟，Agent 能透過 Browser Use 操作同一批頁面；支援彈出視窗與 Passkey。

🧩

Skill 與整合

把含 SKILL.md 的資料夾放進 ~/.vela/skills 即可；Notion 等內建應用一鍵連接，OAuth 在系統瀏覽器完成。

🎨

模型、主題與語言

登入模型提供方、填寫 API 金鑰或新增自訂介面；淺色／深色主題，中英文介面。

本地與安全

Agent 能自己做多少，由你決定

對話、帳號、工作區與執行軌跡都保存在本機 ~/.vela；內建整合的憑據由系統安全儲存加密。

如實說明：權限是互動式審批策略，不是作業系統層級的沙箱；目前只支援在本機工作區或 Git worktree 執行，遠端與隔離沙箱尚未實作。

  • 修改過去的訊息並回退到檢查點，發送前已有的未提交改動會保留。
  • 記憶不會儲存機密、Token 或原始工具輸出；寫入帶 revision 防衝突。
🛡每次詢問最謹慎

執行終端機命令前請你批准；寫入工作區之外的位置也會詢問。

✨幫我批准折衷

由目前對話選用的模型判斷風險，只有風險操作或判斷失敗時才詢問你。

⚡完全存取最流暢

跳過逐項確認，適合你完全信任的任務。

快速開始

幾行指令，從原始碼啟動

目前提供從原始碼啟動。需要 Node.js 22.19 以上與 pnpm 11.24.0（由 packageManager 欄位固定）。

  1. 在「設定 → 模型與帳號」登入模型提供方，或新增自訂介面。
  2. 選擇本機專案目錄或 Git worktree。
  3. 選擇 Agent、Plan 或 Goal，描述你的任務。
zsh — VelaHarness 
# clone & install
git clone https://github.com/KryptonGao/VelaHarness.git
cd VelaHarness
pnpm install

# launch the Electron dev environment
pnpm dev

開發版使用獨立的 ~/.vela-dev 資料目錄，可與已安裝的 Vela.app 同時運行。macOS 發佈包未經公證，首次啟動請在「系統設定 → 隱私權與安全性」選擇「仍要打開」。
