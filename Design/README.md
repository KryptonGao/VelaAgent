# Vela Agent — Native macOS Desktop UI (Codex Inspired)

已根据提供的参考截图全面重构：采用 **左侧半透明冰蓝毛玻璃**、**大圆角**、**超柔和弥散阴影** 以及 **全站无描边（Strict Borderless）** 的现代原生 macOS 桌面设计语言。

---

## 🎨 视觉核心规范对齐

| 视觉维度 | 截图对齐实现细节 |
| :--- | :--- |
| **左侧半透明冰蓝毛玻璃** | `background: rgba(238, 244, 252, 0.78)` 配合 `backdrop-filter: blur(32px) saturate(190%)`，透出系统底层桌面光泽，纯净通透。 |
| **极度温润的大圆角** | 底部悬浮输入 Dock 采用 `border-radius: 26px` 超大胶囊圆角；窗口整体采用 `20px`；已编辑文件及建议卡片采用 `16px`。 |
| **超柔和弥散阴影** | 完全摈弃高对比度硬阴影，改用像 macOS 窗口般的低饱和多层漫反射阴影（`0 12px 36px rgba(15, 23, 42, 0.08)`）。 |
| **坚决不要描边 (No Borders)** | 全站去除所有 `border` 细线描边，仅依靠材质色差（纯白、冰蓝毛玻璃、淡蓝灰卡片）与阴影界定层级边界，质感浑然一体。 |

## 📸 界面三栏架构说明

1. **左侧栏（Frosted Blue Glass）**：
   - 顶部交通灯 `[● ● ●]`、历史前进后退按钮及侧边栏折叠按钮；
   - 工作区下拉切换器 `Vela ⌄` + 搜索与通知快捷入口；
   - 快速入口：`新对话`、`Pull Request`、`定时任务`、`插件`、`探索`；
   - 项目分组树：`studypulse-cloud-ai`、`AgentDoctor`、`StudyPulse`、`DeepTutor-1.6.10`、`Glance`；
   - 当前会话激活胶囊项：`修复 Provider 设置页密钥逻辑`（纯白大圆角浮起高亮）；
   - 底部固定用户信息栏：`Chenkai Gao` 头像、`语音` 药丸按钮与帮助图标。
2. **中间主对话区（纯白背景，无描边，清透舒展）**：
   - 顶部轻盈 Header：当前会话标题、`···` 更多操作、`分享` 按钮、视图切换器；
   - 建议提示蓝调卡片：`agent-blue-card`（`• 建议：...`，大圆角无描边）；
   - **「用时 2分钟 53秒 ∨」可折叠/展开执行流（严格对齐用户新截图）**：
     - 展开后展示完整思考段落与工具调用链路；
     - 包含一级收起简报：`📖 已读取文件运行了命令`；
     - 包含二级折叠：`✎ 编辑了文件读取文件运行了命令 ∨`；
     - 展开展示具体的每一步 Tool 操作流水线（终端命令执行、搜索关键词、连续读取文件、编辑文件代码行数 `+65 -0` 统计）；
     - 点击可平滑折叠/展开，指示箭头动态旋转；
   - 浮动在内容下方的快速滚动按钮 `↓`（纯白圆润软阴影，支持一键滑到底部）；
   - 对话正文说明与可交互的文件代码行标记链接（`</> ProviderSettingsView.swift`）；
   - **已编辑 4 个文件（Tool Calls 卡片）**：纯白卡片、无描边、软阴影，包含 `撤销 ↶`、`审核` 胶囊按钮、文件行与差异统计（`+65 -0`），点击可展开内嵌实时 Git Diff 对比视图；
   - **底部悬浮输入 Dock**：严格还原截图，超大圆角纯白无描边软阴影卡片，内嵌占位符 `随心输入`，底部包含 `+` 按钮、`🛡 完全访问` 橙色安全药丸标签、`✦ GPT-6 Luna 最高 ∨` 模型切换、麦克风图标与蓝色波纹大圆发送按钮。
3. **右侧栏（双模态视图：Todo & Context ⇄ 文件预览与代码检查器）**：
   - **默认状态**：展示 `Todo List & Plan` 任务卡片与 `Context & Token` 仪表盘；
   - **文件预览状态（完全对齐参考截图 3）**：
     - 在界面中**任意点击文件名**（如正文链接、用时流操作项、已编辑文件列表或 Context 文件卡片），右侧栏自动无缝切换为**文件预览面板**，同时**隐藏 Todo 和 Context**，宽度智能扩展至 `640px`；
     - 顶部包含已打开的文件选项卡（`Localizable.xcstrings`、`ProviderSettingsView.swift ×`、新建 `+`），点击 `×` 或返回按钮可随时切回 Todo/Context 面板；
     - 面包屑与快速动作条（`Glance > Glance > ProviderSettingsView.swift`、复制代码、打开菜单）；
     - **左侧：代码预览与行号槽**（真实 Swift 语法高亮、修改行高亮）；
     - **右侧：项目文件目录树**（搜索过滤框、展开目录树、当前选中文件高亮），点击文件树节点也可即时预览切换。

## ⚡ 快捷键与本地查看

* **`Cmd+B`**：折叠/展开左侧蓝毛玻璃导航栏
* **`Cmd+J`**：折叠/展开右侧 Todo List & Context 面板
* **`Cmd+K`**：快速聚焦搜索
* **`Enter`**：在底部大圆角输入框内发送消息并模拟 Agent 思考
